Detailed Description

User settings – the only file most people need to edit.

Everything here is wrapped in #ifndef, which gives four layers, each beating the one below:

  1. a -D flag on the compiler command line (what CI uses)
  2. whatever you uncomment in this file
  3. the board profile in platform.h
  4. the generic defaults at the bottom of platform.h

Runtime appearance – colours, iris size, textures, blink behaviour – lives in config.eye on the USB drive. The values here are the fallbacks used when the drive has no config.
