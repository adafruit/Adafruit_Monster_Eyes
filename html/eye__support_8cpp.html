Detailed Description

BMP loading, config parsing, storage, table generation and media.

Sections, in order:

  1. BMP loading – streaming, 1-bit eyelids and 24-bit textures
  2. Settings – config.eye JSON
  3. Storage – FatFS mount and USB drive mode
  4. Tables – polar and displacement maps
  5. Media – ties files to the renderer, with solid-colour fallback
Note
Requires ArduinoJson 7.x (JsonDocument). On 6.x the declaration in eyeSettingsLoad() becomes StaticJsonDocument<2048>.

Load a 1-bit eyelid bitmap into a pair of sweep tables.

For each column the topmost and bottommost lit pixel become the fully open and fully shut lid positions, flipped into the renderer's frame where +Y is up. The image is scaled to size, so any source dimensions work.

Parameters
rSource of BMP bytes.
openTableReceives the fully-open position per column.
closedTableReceives the fully-shut position per column.
sizeEye size in pixels; both tables hold this many entries.
isUppertrue for the upper lid, false for the lower.
Returns
false if the image is not an uncompressed 1-bit BMP.

Load a 24-bit BMP as an RGB565 texture, decimating it to fit.

Oversized images lose resolution rather than being rejected, so any source works on any board.

Parameters
rSource of BMP bytes.
dataReceives a malloc'd buffer the caller owns.
widthReceives the resulting width.
heightReceives the resulting height.
maxBytesLargest buffer the caller can afford.
Returns
false if the image is not an uncompressed 24-bit BMP, or if even the smallest decimation exceeds maxBytes.

◆ eyePanelReset()

void eyePanelReset ( const int *  rstPins,
int  count 
)

Pulse every distinct reset pin once, before any panel is initialised.

Panels are constructed without a reset pin so that no driver pulses the line itself. With a SHARED reset, the second panel's init would otherwise knock the first back to its power-on state – the symptom being a panel that flashes an image at boot and then stays dark while still receiving pixels.

Duplicate pin numbers are pulsed only once.

Parameters
rstPinsReset GPIO per eye; entries below zero are skipped.
countNumber of entries in rstPins.

bool eyeMediaLoad ( int  size,

)

Load eyelid tables and textures for an eye of size pixels.

Every asset is optional. A missing texture becomes a 1x1 solid colour, which the renderer samples correctly and which still yields a properly sized, dilating pupil; a missing eyelid leaves the sweep tables at their init values, which reads as no eyelid.

Parameters
sizeEye size in pixels.
texBudgetBytes textures may consume in total. Oversized images are decimated to fit rather than rejected.
Returns
false only if the eyelid tables could not be allocated.
