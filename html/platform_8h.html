Detailed Description

Chip abstraction and per-board defaults.

Everything in this project is plain C++ except a handful of calls no Arduino core agrees on. They live here so porting to a new chip means adding one block, not hunting through the render loop.

The board profiles below supply defaults for anything settings.h left open – which panel is likely attached, and which DVI carrier to assume.
